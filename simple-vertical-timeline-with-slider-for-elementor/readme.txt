A customizable, responsive vertical timeline widget with a content slider for Elementor.

== Description ==

Adds a "Vertical Timeline with Slider" widget to Elementor (category: Vertical Timeline). Visitors click a milestone on the vertical timeline, or use the prev / next buttons, to slide through your story.

* Unlimited milestones (year, label, date chip, title, description, highlight number and label)
* Vertical timeline with a slide panel on desktop, stacked layout on tablet, vertical accordion on mobile
* Custom breakpoints for tablet and mobile layouts
* Light and Dark color palettes with optional automatic dark mode
* Typography, spacing, border, radius and shadow controls (responsive where it matters)
* Prev / next buttons, keyboard arrows, optional autoplay
* Accessible markup (aria-expanded, aria-current, focus styles, reduced-motion support)
* No external services, no tracking, no data collected

This plugin requires the free Elementor plugin. It is an independent add-on and is not affiliated with or endorsed by Elementor Ltd.

== Installation ==

1. Make sure Elementor (3.5 or newer) is installed and active.
2. Upload the plugin ZIP via Plugins > Add New > Upload Plugin, then activate it.
3. Edit a page with Elementor, search for "Vertical Timeline" and drag the widget onto the page.

== Frequently Asked Questions ==

= Does this plugin need Elementor? =

Yes. It adds a widget to Elementor and does nothing without it.

= Can I turn on autoplay? =

Yes. Enable Autoplay in the widget's Settings section. Autoplay is disabled inside the Elementor editor and stops once the visitor interacts with the timeline.
